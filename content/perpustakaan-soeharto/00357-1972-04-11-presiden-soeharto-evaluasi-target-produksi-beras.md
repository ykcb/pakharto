# 1972-04-11 Presiden Soeharto Evaluasi Target Produksi Beras

# Presiden Soeharto Evaluasi Target Produksi Beras1

SELASA, 11 APRIL  1972, Dalam sidang Sub-Dewan Stabilisasi Ekonomi hari ini di Bina Graha, Presiden Soeharto meminta kepada Menteri Pertanian untuk meninjau kembali target produksi beras yang akhir Pelita 1 ditetapkan akan mencapai 15,4 juta ton. Menurut Presiden, penurunan target produksi diperlukan mengingat bahwa kalau target tersebut tercapai, maka akan terjadi *over supply* produksi beras. Bila hal ini terjadi maka dikhawatirkan akan mengakibatkan turunnya harga beras, sehingga merugikan petani. (AFR)
