# 1972-09-20 Presiden Soeharto Resmikan Jembatan Kereta Api Serayu

14 September 2013  [Soeharto Library](https://soehartolibrary.id/author/cyril/)  [No Comment](https://soehartolibrary.id/1972-09-20-presiden-soeharto-resmikan-jembatan-kereta-api-serayu/#respond)  129 Views Share on

# Presiden Soeharto Resmikan Jembatan Kereta Api Serayu

## Hadiahkan Kerbau Kepada Warga Desa [[1]](#_ftn1)

**RABU, 20 SEPTEMBER** **1972**Hari ini Presiden Soeharto meresmikan jembatan kereta api Sungai Serayu di Kebasen, Jawa Tengah. Dalam kata sambutannya Presiden mengatakan bahwa peranan kereta api sebagai sarana angkutan adalah sangat penting. Oleh karena itu dalam Repelita sekarang, pemerintah mempunyai kebijaksanaan untuk mengembalikan kereta api pada peranan pokoknya, yaitu sebagai sarana angkutan barang jarak jauh, disamping sebagai alat transportasi penumpang.

Pada kesempatan itu Presiden Soeharto telah menghadiahkan enam ekor kerbau kepada enam orang penduduk Desa Kali Bumiayu atas jasa-jasanya menyelamatkan kecelakaan kereta api akibat runtuhnya jembatan. (AFR)
