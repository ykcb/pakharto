# 1970-01-04 Presiden Soeharto Lancarkan Program Pengumpulan Dana Untuk Irian Barat

# **Presiden Soeharto Lancarkan Program Pengumpulan Dana Untuk Irian Barat[**[1]**](#_ftn1)**

MINGGU, 4 JANUARI 1970, Presiden Soeharto melancarkan suatu program pengumpulan dana bagi rakyat di Irian Barat. Kegiatan yang diselenggarakan di Istana Bogor ini dimeriahkan oleh sejumlah artis ibukota. Dalam sambutannya Presiden Soeharto mengatakan bahwa proyek kemanusiaan ini sebenarnya hanya dimaksudkan untuk menghimbau para dermawan yang hartawan untuk membantu putera-puteri Irian Barat dalam bidang pendidikan. Tetapi kenyataannya segala lapisan masyarakat telah turut membantu. (AFR)
